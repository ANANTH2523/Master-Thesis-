# Master's Thesis Cross-Scenario Threat Modeling Summary Report
## Comparative Evaluation of ThreMoLIA Architecture-Grounded Findings

### 1. Executive Summary
This report summarizes the **cleaning, normalization, deduplication, and architectural validation** performed on the raw experimental output generated by ThreMoLIA across all three evaluation scenarios.

The primary objective of this normalization is to establish an **academically defensible dataset** for Master's thesis evaluation, enforcing strict anti-hallucination standards, removing mechanical STRIDE redundancies, and providing explicit evidence traceability.

### 3. Scenario Architectural Overviews

1. **Scenario 1 — LLM-Integrated Authentication Assistant System**:
   - **Focus**: Traditional user authentication (P2, DS1, DS2) combined with informational AI chatbot support (P4, P5, EE2).
   - **Key Validated Vectors**: Login brute-forcing, user enumeration, password hashing DoS, session hijacking/fixation, prompt injection, and prompt context secret leakage.
   
2. **Scenario 2 — LLM-Integrated Secure File Management System**:
   - **Focus**: Secure file storage, retrieval, and access control (P2, DS1, DS2) with document AI assistance (P3, P4, EE2).
   - **Key Validated Vectors**: Broken Object-Level Authorization (BOLA), path traversal file overwrites, zip bomb storage DoS, indirect prompt injection via uploaded documents, and unauthorized context retrieval bypass.

3. **Scenario 3 — LLM-Integrated Account Recovery and Profile Management System**:
   - **Focus**: State-sensitive recovery verification (P2, DS2) and profile mutation (P3, DS1) with AI account support (P4, P5, EE2).
   - **Key Validated Vectors**: Recovery token prediction/brute-forcing, token replay (non-atomic invalidation), recovery user enumeration, mass assignment profile privilege escalation, and recovery credential prompt leakage.

### 4. Methodological Grounding & Anti-Hallucination Adherence
- **Data Layer Separation**: Raw outputs are preserved in Layer 1 (`scenarioX_raw.*` / `sce X thremolia.csv`) while canonical normalized findings are structured in Layer 2 (`scenarioX_normalized.xlsx` / `all_scenarios_normalized_master.xlsx`).
- **No Invented Infrastructure**: Technologies such as Redis, SIEM, WAF, or Kubernetes were not injected into threat descriptions or mitigations unless explicitly present.
- **Metric Integrity**: Raw finding counts are not used as denominators for coverage calculations.
